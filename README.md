\# Lab03 — Чанарын сценарио → SLO → k6 threshold



Хичээл: F.CSA313 — Программ хангамжийн чанарын баталгаа ба тест



\## 1. Зорилго



Express API-ийн гүйцэтгэл, найдвартай байдал, хүртээмжийг чанарын сценарио, SLO болон k6 threshold ашиглан шалгах.



\## 2. Чанарын сценарио



\### 2.1. Performance — Гүйцэтгэл



| Хэсэг | Тайлбар |

|---|---|

| Тойм | Сагсанд бүтээгдэхүүн нэмэх үйлдлийн гүйцэтгэл |

| Системийн төлөв | Express API хэвийн ажиллаж байгаа |

| Орчны төлөв | 20 VU, 1 минут, төлөвлөсөн ачаалал ойролцоогоор 15 cart хүсэлт/секунд |

| Гадаад өдөөлт | Хэрэглэгч POST /cart/add хүсэлт илгээнэ |

| Шаардлагатай хариу | HTTP 200 болон JSON хариу буцаана |

| Хэмжүүр | p95 < 200 мс |



\### 2.2. Reliability — Найдвартай байдал



| Хэсэг | Тайлбар |

|---|---|

| Тойм | Төлбөрийн үйлдлийн найдвартай байдал |

| Системийн төлөв | Express API хэвийн ажиллаж байгаа |

| Орчны төлөв | 20 VU, 1 минут |

| Гадаад өдөөлт | Хэрэглэгч POST /pay хүсэлт илгээнэ |

| Шаардлагатай хариу | Төлбөр амжилттай боловсруулагдаж HTTP 200 буцаана |

| Хэмжүүр | POFOD буюу error rate < 8% |



\### 2.3. Availability — Хүртээмж



| Хэсэг | Тайлбар |

|---|---|

| Тойм | Эвдрэлийн дараах системийн хүртээмж |

| Системийн төлөв | Сервер ажиллаж байгаад гэнэт зогсоно |

| Орчны төлөв | 20 VU, 2 минут |

| Гадаад өдөөлт | Серверийн 10 секундийн зориудын зогсолт |

| Шаардлагатай хариу | Сервер дахин асаж, хүсэлт хүлээн авдаг болно |

| Хэмжүүр | Availability > 90%, сэргэх хугацаа 12 секундээс ихгүй |
